# Urban Gang Tour master goal

## Objective

Build and production-verify the complete Urban Gang Tour operating system:

- public conversion and SEO
- role-scoped Control Room workflows
- events
- ticketing
- payments
- scanning
- refunds
- documents and branded generators
- merch variants, stock and fulfilment
- supplier production
- event and relationship operations
- content and media workflows
- reporting
- safe automations
- authenticated end-to-end verification
- production verification

## Operating constraints

- Do not invent commercial or operational facts.
- Preserve existing user changes unless a verified defect or explicit direction requires a change.
- Keep implementation, local verification, integration verification, browser verification and production verification distinct.
- Work one bounded vertical workflow at a time. The active workflow and evidence belong in `WORK-MANIFEST.md`.
- Do not declare the goal complete until each objective area has current authoritative evidence.

## Continuity

`WORK-MANIFEST.md` is the active execution checkpoint. It records the current changed files, verified evidence, blockers, remaining workflow order and exactly one next implementation bundle.
