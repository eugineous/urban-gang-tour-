Direction: energetic event posters, calm booking desk. Retain magenta, real host art/posters, MOOKH/Nixtio desktop, Eventify mobile and Mkurugenzi shop. Refine shared rhythm, contrast, type and states rather than replacing the product. Normal small-text tracking, tabular figures, simpler controls/surfaces and lighter ordinary headings apply across the existing page families. The Contact chooser retains /apply and both destinations, with a clearer title and no repeated greeting.

Overlays use the real trigger's centre in percentage coordinates; keyboard and normalized zoom are covered. Automatic campaigns/invitations explicitly opt out of unrelated click attribution. Components retain focus/open/close ownership; dismissed dialogs disappear immediately rather than leaving a fading hit box. No network/storage or financial effects are added. Loading uses reserved neutral geometry, not a spinning logo or invented progress. Checkout retains one semantic progress indicator, stable headings and a reserved accurate connection status area.
