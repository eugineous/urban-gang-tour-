# Urban News interface decisions

Preserve the existing magenta/neutral design tokens, Inter, owner imagery and
44px controls. The homepage orders news, events and merchandise; no invented
stories fill an empty feed. Phone dock: News, Events, central Home, Shop, Contact;
guest tickets stay prominent in the header. Legacy mode restores the prior UI.

Reuse existing fields, image upload, Control Room navigation and CSS modules.
The newsroom has one inbox/editor workspace, compact source disclosures and an
explicit saved-revision review. Use stable loading space, retained typed text on
conflict, immediate button feedback and reduced-motion support. Keys and automation
are progressively disclosed behind the owner-only setup section.

The 21st CLI context search was attempted but unavailable without sign-in. No
hosted generation, signup or paid resources were used. Actual Chromium tests cover
320/390/1440 public layouts, six languages, keyboard navigation and mobile editing.
