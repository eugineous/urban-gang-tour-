# UGT Marketing Website — UI Kit

Click-through prototype of the Urban Gang Tour marketing site. Brand-mode B (stage/concert) for the hero, mode A (sticker/scrapbook) for content sections.

## Screens
1. **Home** — hero, marquee, calendar, about, partners, sponsor CTA, footer.
2. **Apply** — "bring UGT to your school" form.
3. **Event** — single-school event detail page.

## Components
- `TopNav.jsx` — fixed top nav with logo + sticky CTA.
- `HeroStage.jsx` — black stage hero with glow.
- `Marquee.jsx` — motto ticker.
- `EventCard.jsx` — sticker card with tape.
- `PartnerGrid.jsx` — partner logos + description.
- `SponsorTiers.jsx` — the four-tier pricing/scope grid.
- `Footer.jsx` — magenta scrapbook footer.

Open `index.html` to see all three screens wired together.
